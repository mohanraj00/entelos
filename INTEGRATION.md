# Integration boundary

The host installs actor/role/scope/function/runner/worker context. A request cannot grant itself authority. The local context-file adapter demonstrates that split; another process owned by the same OS user can bypass it. Production authentication, authorization and redaction are application work.

The host also supplies approved source interpretation, independent cases and admission policy. Passing a case set is not evidence that the source is true. A producer cannot submit a passed flag and activate it. Qualification binds its exact snapshot, source, case plan and build before a separate reviewer decision.

Dates are supplied explicitly as canonical ISO dates, with half-open intervals and exact scope equality. Replacement/suspension names earlier targets and masks only its own interval. There is no version sort, timestamp tie-breaker or fallback after suspension. New evidence blocks fresh admission on its replaced interval; stopping active content is an explicit operation.

Content identity hashes media type, NUL and exact bytes. Reformatting may create another identity. Git commits are accepted history cursors, not computation content identities. Only one root ref publishes state; a stale writer must re-evaluate. A success key is checked before a stale-version failure. Same key with a changed payload is a conflict. Namespace request keys across consumers. Configure separate preparation slots where the one-slot worker model requires them.

A receipt stores the host's fixed JSON encoding of the normalized input object, not the original request frame's whitespace. Replay uses the old receipt's input/snapshot/build without resolving latest. Restatement requires an explicit later accepted cursor and reason. It calculates a new answer; it does not perform a refund, pipeline launch or another side effect. Permission to serve and permission to replay are separate policies.

The CI projection and audit code is an application example. Verification is simulated by host context. The sidecar stores raw-event/projection/input/receipt links outside the generic Git transaction. A real host must supply raw-input retention, ingress verification, delivery deduplication, audit reconciliation and side-effect idempotency. Do not describe that sidecar as an atomic authenticated ingress receipt.

An oversized JSONL line closes the stream with an error; a trailing fragment cannot become another command. Audit file references require the exact content-ID syntax. Audit verification checks the retained record's own identity, including its receipt association, before checking retained dependencies. Those byte checks do not authenticate the sender.

The runtime port also accepts the example's frozen ordinary functions. Their profile/build differs from CEL, and they do not implement CEL parser/cost semantics. The common lifecycle in both comparison paths cannot establish its superiority over other lifecycle systems.
