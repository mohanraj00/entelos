# Licence decision

2026-10-29. [Tracked change](https://github.com/mohanraj00/entelos/issues/5).

I use [Apache-2.0](../LICENSE) for this project's original source. I chose its explicit contributor patent terms for code intended to be reused in other systems. The licence defines the scope and conditions of that grant; this choice is not a guarantee against patent claims. Source-reference support and API limits remain unchanged.

[NOTICE](../NOTICE) retains the existing project copyright attribution. [CONTRIBUTING.md](../CONTRIBUTING.md) identifies the terms for contributions. Dependencies keep their own licences and notices, listed in [THIRD_PARTY.md](../licenses/THIRD_PARTY.md).

The initial published revision, [991a81d2a08f6d8e052ecdf0d62a7569888ca714](https://github.com/mohanraj00/entelos/commit/991a81d2a08f6d8e052ecdf0d62a7569888ca714), contained an MIT licence. That history is retained. This revision changes the project's current licence to Apache-2.0; it does not rewrite prior commits or change upstream dependency terms.

This is a licence/documentation change. Runtime code, examples, fixtures, dependency pins and retained third-party licence/NOTICE texts are unchanged.
