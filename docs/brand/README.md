# Brand assets

Entelos: grow toward the goal.

## Files

| File | Use |
|---|---|
| `entelos-logo-light.svg` | Logo on a light background |
| `entelos-logo-dark.svg` | Logo on a dark background |
| `entelos-mark-light.svg` | Mark alone on a light background |
| `entelos-mark-dark.svg` | Mark alone on a dark background, for example an avatar |
| `entelos-social.png` | GitHub social preview, 1280×640 |

The mark is three open rings around a center dot. The dot is the goal. The open part of each ring makes a path from the outside to the center. The wordmark is drawn with strokes, so the SVG files do not need a font.

## Rules

- Do not change the ring proportions or the stroke width.
- Do not put the light logo on a dark background. Use the dark file.
- Keep clear space around the mark of at least the width of one ring gap.
